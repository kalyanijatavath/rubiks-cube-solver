# Stage 7: positioning the top edges

*id: n11_edge_perm - tag: stage7*

Goal: the cube is solved. With the top corners correct, find a top edge that is already in place and hold the cube so it is at the back. Run R U' R U R U R U' R' U' R2. This cycles the other three top edges and leaves the corners alone. If the edges are cycled the wrong way, run it once more; three runs return you to the start, so at most two runs are needed. If no top edge is correct, run the algorithm once from any angle and look again.
