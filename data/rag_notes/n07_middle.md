# Stage 3: the middle layer edges

*id: n07_middle - tag: stage3*

Goal: the four middle-layer edges are in place, finishing the first two layers. Look for an edge in the top layer that has no top-color (yellow) sticker. Turn the top layer until the sticker on the front face matches the front center. If the sticker on top matches the right center, run U R U' R' U' F' U F. If it matches the left center, run U' L' U L U F U' F'. Both algorithms leave the bottom layer solved once they finish. If a middle-layer edge is stuck in the wrong slot, run either algorithm with that edge in the working slot to pop it out into the top layer, then insert it properly.
